# E-Commerce Sales Dashboard

## Project Overview
This project is an interactive Excel dashboard created to analyze e-commerce sales performance, customer behavior, and order trends across multiple channels and states.

The dashboard helps identify key business insights related to revenue, customer demographics, order status, and sales channels.

---

## Problem Statement
Businesses often struggle to track sales performance, customer purchasing behavior, and operational issues across different channels.

This dashboard aims to:
- Analyze overall sales performance
- Identify top-performing categories and states
- Understand customer demographics
- Monitor order cancellations and returns
- Compare sales channels

---

## Dataset Information
The dataset contains:
- Order details
- Customer demographics
- Product categories
- Sales amount
- Order status
- Sales channels
- Shipping locations

---

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- KPI Cards

---

## Business Questions Solved

### Sales Analysis
- Which channel generates the highest revenue?
- Which states contribute the most sales?
- What are the monthly sales trends?

### Customer Analysis
- Which gender purchases more?
- Which age group contributes most orders?

### Operational Analysis
- What percentage of orders are returned/cancelled?
- Which channels face higher return rates?

---

## Dashboard Features
- Interactive slicers
- Dynamic KPI cards
- Monthly sales trend analysis
- Channel-wise sales analysis
- State-wise revenue analysis
- Customer demographic insights

---

## Key Insights
- Amazon contributed the highest share of total revenue.
- Women customers generated higher order volume compared to men.
- Maharashtra and Karnataka were among the top-performing states.
- Delivered orders accounted for the majority of total orders.
